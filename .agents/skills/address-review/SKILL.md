# Address review

Check new comments in an opened pull request and address them: improve the code and say about that in the comment or explain
why the comment shouldn't be addressed.

Use `eyes` reaction to indicate that you've read the comment and start working on it. 
Remove the reaction after you've finished addressing the comment.
Don't start working on a comment if it already has `eyes` reaction.
