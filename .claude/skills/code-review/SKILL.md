# code-review

Review the change and list findings, most severe first. For each: `file:line`, what is wrong, and a concrete case
that shows it. Separate **blocking** issues (bugs, spec mismatches, missing tests) from
**suggestions** (naming, simplification). Say plainly when nothing was found. Be short and precise.
